근거 문장을 확인하고 승인만 하세요.

전사본을 넣으면 AI가 결정사항, 내 할 일, 개발자 확인 요청, 다시 물어볼 것으로 나눠요. "다음 주 수요일"은 날짜로 바꾸고, 확정할 수 없는 기한은 비워 둬요. PM이 승인한 것만 한 보드에 기한 순서로 쌓여요.

회의 후속 정리기

  • 정해진 칸으로 나누고 항목마다 근거 문장을 달아요
  • 결론이 없으면 '다시 물어볼 것'으로 따로 모아요
  • 할 일과 확인 요청이 한 보드에 기한 순으로 쌓여요
  • '오늘' 화면에서 기한 지남·오늘·3일 안·미정을 한눈에 봐요
  • BM 논의는 별도 칸에, AI 가설은 채택한 것만 남겨요

안전장치

AI가 틀려도 그대로 나가지 않게

승인 전에는 저장되지 않아요

AI 초안은 검토 화면에만 있어요. PM이 이름을 적고 승인해야 보드와 정리본에 남아요.

날짜와 숫자를 지어내지 않아요

전사본에 없는 숫자·날짜·이름은 쓰지 않아요. 확정할 수 없는 기한은 비워 두고 표시해요.

다시 정리해도 기록이 남아요

재분석하면 새 버전이 생기고, 이전 승인본과 이미 완료한 항목은 그대로 보존돼요.

모든 변경이 이력에 남아요

등록·초안·승인·상태 변경·삭제까지 누가 언제 했는지 지워지지 않는 기록으로 쌓여요.

함께 들어 있는 기능 · 정책 Q&A 정책 문서만 근거로 답하고 인용문을 원문과 다시 대조해요 · 문구 검수 기획서·공지를 사이트 표기 기준과 대조해요

비용

쓰는 만큼만 API 요금이 나와요

회의를 정리할 때마다 Claude API를 한 번 불러요. 요금은 고객사 API 계정으로 청구되고, 이미 쓰는 AI 구독과는 별개예요.
