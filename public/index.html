오늘 챙길 것

승인한 회의에서 나온 할 일·확인 요청이에요. 상태를 바꾸면 노션 카드도 함께 바뀌고, 기한 미정 항목은 날짜를 바로 정할 수 있어요.

바로가기

회의 내용 넣기

음성기록(.txt)이나 녹음 파일을 넣으면 AI가 초안을 만들고, PM이 검토·승인해야 저장돼요.

음성기록 .txt 파일을 끌어다 놓거나

25MB 이하. 변환된 텍스트는 아래에서 고친 뒤 정리하세요.

할 일 보드

승인한 회의에서 나온 항목이 상태별로 쌓여요. 카드는 기한이 가까운 순서예요.

정책 Q&A

노션·지라에서 가져온 정책 문서만 근거로 답해요. 문서에 없으면 모른다고 답하고, 인용문이 원문과 같은지 시스템이 다시 확인해요.

최근 질문

문구 검수

기획서·공지 문구가 실제 사이트 화면 표기(노션 UI 문구 용어집)와 맞는지 확인하고, 검수 결과를 파일로 남겨요.
